# 🎯 园区Skill智能方案生成平台

> 一个功能完整的AI驱动的园区数字化解决方案生成和管理平台

![Version](https://img.shields.io/badge/version-1.0.0-blue)
![License](https://img.shields.io/badge/license-MIT-green)

## ✨ 核心功能

- 📚 完整的方案库 - 15个园区类型，100+资料文件
- 🔄 三阶段销售流程 - 售前→售中→交付
- 🤖 智能生成工具 - 一键生成方案和PPT
- 🌐 现代化网页界面 - 响应式，深色护眼
- 🔌 完整的API服务 - 8个REST端点

## 🚀 快速开始

```bash
npm install
npm start
# 打开 http://localhost:3000
```

## 📦 使用Docker

```bash
docker-compose up -d
```
